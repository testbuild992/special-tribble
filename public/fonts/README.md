# Fonts

The BIJI brand font is **Winden** by Latinotype (commercial licence).

Place the licensed webfont files here so the site picks them up automatically:

- `Winden-Regular.woff2` (or `.ttf`)
- `Winden-Bold.woff2` (or `.ttf`)

Until then the site falls back to **Zilla Slab** (free, loaded from Google Fonts),
which keeps the same slab-serif character.
